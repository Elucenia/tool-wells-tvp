# 深部静脈血栓症のWellsスコア

[条件・出典・許諾](https://elucenia.org/ja/tools/wells-tvp)

## 使い方

ポータルでツールを使用するか、ローカルHTTPサーバー経由でindex.htmlを開いてください。言語を選択し、項目を入力して計算してください。

## 入力項目と単位

### 活動性がん（過去6か月以内の治療、または緩和治療）

`cancer`

### 下肢麻痺・不全麻痺または最近のギプス固定

`paralisia`

### ≥ 3日間の臥床、または過去12週間に全身麻酔もしくは区域麻酔を必要とする大手術

`acamado`

### 深部静脈の走行に沿った限局性圧痛

`dor_trajeto`

### 下肢全体の腫脹

`edema_total`

### 下腿周径が対側より≥ 3 cm大きい（脛骨粗面の10 cm下で測定）

`panturrilha`

### 症状のある下肢に限局した圧痕性浮腫

`cacifo`

### 側副表在静脈（静脈瘤ではない）

`colaterais`

### 記録された深部静脈血栓症の既往

`tvp_prev`

### 深部静脈血栓症と同程度以上に考えられる代替診断

`alternativo`

## 方法の版

Wells DVT 2003、表1：9因子+代替診断−2。2段階≥2 / \<2。3段階モデルは別に表示し、その版はまだ確認していない

## 記載された計算式

各項目1点（がん、麻痺/ギプス固定、臥床または手術、静脈走行に沿った圧痛、下肢全体の腫脹、下腿周径の増大≥ 3 cm、片側の圧痕性浮腫、側副静脈、DVT既往）。代替診断が同程度以上に疑わしければ−2点。

2段階（Wells 2003）：≥ 2 = DVTの可能性が高い；≤ 1 = 可能性が低い。3段階：≤ 0低；1–2中等度；≥ 3高。

## 限界・対象集団

Wells 2003の方針は、下肢の深部静脈血栓症（DVT）が疑われる外来患者で研究されました。プロトコルに従って超音波検査を省略するには、臨床的な可能性が低く、Dダイマーが陰性であることの両方が必要でした。スコアだけではDVTを確定も除外もできず、Dダイマー測定法と適格基準は使用するプロトコルに対応する必要があります。 Wells 2003の表1では、下腿周径差は少なくとも3 cmで、脛骨粗面の10 cm下で測定する。過去12週間の大手術は全身麻酔または区域麻酔を必要とするもの。表は2段階モデル（≥2可能性が高い；\<2可能性が低い）のみを定義しており、ここに表示する3段階モデルの版は未確認のままである。

## 技術テストの再現

```sh
node test.cjs
```
